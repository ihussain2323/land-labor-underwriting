# Underwrite a Land Labor Capital acquisition

When the deal lead supplies a property or deal room and asks for a screen, deliver a saved, recalculated deal copy and a short review of the result. Run the steps below through the handoff in the same pass. A missing seller document can leave a diligence item open while the supported underwriting proceeds.

1. **Establish the subject and interest.** Use the requested account. Match the latest relevant email thread, meeting, offering memorandum and room to address, seller and valuation date. Use Granola for current deal instructions and Otter for earlier reviews. Search the specified mailbox in Chrome if the connected mailbox is different. Prefer the supplied room link and inspect its inventory. Distinguish ownership of apartments, retail, parking, amenities, condo charges and taxes. Resolve an ambiguous property or workbook before writing.
2. **Open the deal copy.** Identify the master and the completed comparison models. Make one named property copy of the master or resume the verified existing deal copy. Use the connected Excel workflow for a live workbook. For files, use the available spreadsheet workflow and recalculate in Excel. Keep a pre-edit revision or recoverable version. A new run starts with its own deal record. On refresh preserve intentional analyst edits and report discrepancies against the prior readback.
3. **Build the evidence record.** Start from [the deal record](assets/deal-start.json). Apply [the decision rules](references/decision-rules.md) and [documented underwriting precedents](references/underwriting-conventions.md). Identify credible material for each input, its units, scenario, reference date and destination. For unknowns, state the source searched, financial impact and evidence needed. Make screening assumptions explicit. Avoid adding a sheet if existing input notes or a small review area serve the purpose.
4. **Reconcile before writing.** Match unit IDs in the rent roll to the OM, area schedule and lease information. Preserve leading zeros and exclude retained units. Rebuild the twelve monthly expense totals from seller detail, preserving credits. Check ZIP rent and value history against dated projections. Use [the execution guide](references/run.md) for the supplied Python commands and expected results.
5. **Map and populate.** Use [the workbook map](references/workbook-map.md) with the actual version open. Inspect labels, adjacent units, years, dropdowns, input colors and existing formulas. Start with Transaction Inputs and Asset Inputs. Import seller history into T-12. Review the planned edits and complete the fields marked for resolution. Write supported blue inputs in coherent blocks, then read them back. Preserve working formulas. When a copied template contains a demonstrable reporting defect, trace it to its source, correct the deal copy within scope and disclose the correction. After an interrupted write, compare actual versus planned values and apply only the remaining edits.
6. **Model the applicable cases.** Start with the sourced operating case and any documented gap allowances. Compare seller and benchmark expenses with consistent rent, taxes and financing. For an abatement, assumable debt, mixed uses, phased renovations or a promote, use [the conditional cases](references/cases-and-checks.md). Carry requested scenarios through cash flow with the supported timing. If the evidence supports an illustration only, describe the bounds and the part still unmodeled.
7. **Recalculate and verify.** Capture results from Excel after full recalculation and read back the exact inputs changed. Run source and workbook verification. Trace active errors to fixes, document inherited errors in inactive branches, and distinguish an unavailable result from a genuine zero. Save the intended case, reopen or read it back, and verify that dashboard and executive summary show that case.
8. **Hand off to the deal lead.** Provide the workbook, purchase price, Year 1 NOI and cap rate, equity check, debt coverage and dated levered IRR where supported. State the largest assumption affecting price or returns and list the specific items the team or the seller can resolve. Identify figures as actual, screening or upside. After the team reviews the next building, update this skill for repeatable rules and record the source and scope of each change. Keep deal-specific overrides with their deal.

The Python utilities read local files and calculate checks. The agent handles source retrieval, evidence interpretation, Excel edits, recalculation and save. On a system without a particular connector, use the corresponding user-authorized app or supplied export. If Excel cannot recalculate, report the workbook as prepared with verification outstanding.
